# Markdown Resume（最小独立版）

一个只做一件事的简历工具：**写 Markdown → 实时 A4 预览 → 浏览器打印成 PDF**。

从原 `site/`（Nuxt + 多简历管理 + PWA + i18n + 设置面板……）中抽出来的最小实现，
依赖只有 `vue`、`vite`、`markdown-it`、`markdown-it-deflist`。

## 启动

```bash
cd frontend
pnpm install
pnpm dev
```

构建静态文件：

```bash
pnpm build     # 产物在 frontend/dist
pnpm preview   # 本地预览构建产物
```

## 保留的功能

- Markdown 编辑与实时预览
- **默认简历即使用说明**：`src/assets/default-resume.md` 的版式就是示例，
  各节的正文直接写成简历写作建议（带小标题），末尾还附了 Markdown 语法说明，
  照着替换成自己的内容即可
- **左右分栏可拖动**：拖中间的分隔条调整编辑区宽度（20%–80%，
  且两侧都有最小宽度），双击分隔条复位，聚焦后可用 ← / → 微调；
  宽度自动保存。窗口窄于 900px 时改为上下堆叠
- A4 自动分页（基于 DOM 测量，不是固定行数）
- 实时页数提示（「共 N 页」+ 末页剩余行数）与预览页边界虚线
  （虚线只用于屏幕预览，打印时自动隐藏）
- **排版调节托盘**（右上角）：9 个排版 token 实时调节，可拖动、可收起，
  自动保存，可一键复制配置或恢复默认（打印时自动隐藏）
- 定义列表条目首行三段式单行（时间左 / 名称居中 / 角色右）
- `\newpage` 强制分页
- `\\[10px]` 手动增加垂直间距
- **固定右上角照片位**：标准一寸 25 × 35mm，上传后自动居中裁剪；
  没有照片时保留同尺寸虚线占位框

- 正文图片插入：等比缩放到最大 600px、JPEG 质量 0.78、base64 内嵌
- 下载 `.md`（只含文字；照片仅用于预览与打印/PDF）
- **导出/导入备份**：一个 `.json` 同时带走正文、照片和排版设置
- 浏览器打印 / 另存为 PDF
- 内容自动存到 `localStorage`
  （正文：`markdown-resume-content`，照片：`markdown-resume-photo`，
  排版：`markdown-resume-settings`，分栏：`markdown-resume-split`）
- `localStorage` 不可用时（隐私模式、禁用站点数据、部分浏览器打开
  `file://`）退回「不持久化」状态：应用照常可用，只是刷新后不保留，
  需要自己「导出备份」

## 备份与恢复

「导出备份」下载 `resume-backup-YYYY-MM-DD.json`，结构如下：

```json
{
  "format": "markdown-resume",
  "version": 1,
  "exportedAt": "2026-10-23T08:00:00.000Z",
  "markdown": "# 张三\n...",
  "photo": "data:image/jpeg;base64,...",
  "settings": { "fsBase": 10.5, "lhBody": 1.4, "...": "..." }
}
```

「导入备份」会先校验 `format`，再逐项收紧 `settings`
（缺字段/越界/非数字回退默认值），最后**覆盖**当前正文、照片与排版，
导入前会弹确认框。照片缺失或不是 `data:image/...` 时按无照片处理。

浏览器存储是按来源隔离的：`localhost`、线上域名、`file://` 三者互不相通，
换来源后看不到旧数据是正常的，用这份备份迁移即可。

## 排版调节托盘

右上角的悬浮面板（宽 272px）控制全页排版。按住深色标题栏可拖动，
点「—」收起为圆钮；所有修改即时生效，并写入 `markdown-resume-settings`。

| 分组 | 控件 | 默认 | 范围 | 步进 | 单位 |
| --- | --- | --- | --- | --- | --- |
| 全局基准 | 正文字号 | 10.5 | 9–14 | 0.5 | pt |
| 全局基准 | 正文行距 | 1.4 | 1.2–1.8 | 0.05 | × |
| 元素字号倍数 | 姓名 | 2.0 | 1.5–3.0 | 0.1 | × |
| 元素字号倍数 | 小节标题 | 1.25 | 1.1–1.6 | 0.05 | × |
| 元素字号倍数 | 条目头三段 | 1.05 | 1.0–1.2 | 0.05 | × |
| 间距与页边距 | 段落间距 | 0.3 | 0–1.0 | 0.05 | 行 |
| 间距与页边距 | 小节间距 | 0.5 | 0–3.0 | 0.1 | 行 |
| 间距与页边距 | 左右页边距 | 5 | 3–8 | 0.5 | % 页宽 |
| 间距与页边距 | 上下页边距 | 3 | 2–6 | 0.5 | % 页高 |

- **步进**：点「−」「+」走一档；按住 300ms 后每 120ms 连发，到边界自动停。
- **直接键入**：失焦或回车生效，最多两位小数；越界夹取到边界，
  非数字回退原值并抖动提示；单位固定显示在输入框内。
- **联动**：正文字号或行距变化时，其余字号按倍数、所有以「行」为单位的间距
  按行高同步变化；段落间距作用于列表项之间、条目之间、条目头→首条列表，
  三处始终同值。
- **底部按钮**：复制配置（9 个 token 的 JSON 到剪贴板）、恢复默认
  （同时清空排版配置的本地存储；正文与照片不受影响）、打印/存 PDF。

## Markdown 约定

### 头部（姓名 / 求职意向 / 联系方式）

第一个 `h1` 是姓名；其后、第一个 `##` 或列表之前的段落构成头部，
最后一个段落被当作联系方式行。

- 求职意向行和联系方式行里**手输的空格按原样显示**，连续多个空格不会被
  HTML 折叠成一个，可以直接用空格微调「电话 … 邮箱」等信息的间距；
  行太长时仍然可以在空格处换行
- 联系方式行如果用 `·`、`•`、`|`、`｜` 分隔各项，这些分隔符会被去掉，
  各项之间固定换成两个空格；没有分隔符时整行原样保留

### 定义列表（条目首行）

```markdown
**高级前端工程师**
  : **某某科技有限公司**
  : **2022.07 - 至今**
```

渲染后条目首行是三段式单行：

- 第一行 `dt`：角色 / 职位 / 学位，右对齐
- 第一条 `:` 行：公司 / 学校 / 项目名，在内容区水平居中
- 最后一条 `:` 行：时间，左对齐

名称 + 角色超过内容区约 70% 时，名称会自动降级为紧跟时间左对齐；
仍放不下则省略号截断，不会折行。

### 强制分页

单独一行写：

```markdown
\newpage
```

### 固定照片位

照片固定在姓名右侧、顶部与姓名行齐平（整体上移约 0.2 行），按**标准一寸照**处理：

- 显示尺寸固定为 **25mm × 35mm**（5:7），不随字号缩放
- 图片精确输出为 **295 × 413 像素**（300dpi），点击「上传照片」后按 5:7
  比例**居中裁剪**，再压缩为 JPEG；显示时 `object-fit: cover`
- 右缘贴内容区右缘，与左侧文字保持 **8mm** 间距；文字不会跑到照片下方
- 照片只存在 `localStorage`（`markdown-resume-photo`），用于预览和打印/PDF；
  **下载的 `.md` 只包含文字，不再写入照片**
- 没有照片时保留同尺寸虚线占位框（「照片」字样），版面占位不变；
  图片加载失败时也会退回这个占位框
- 头部高度由三行文字决定，照片不撑高头部：照片浮动在右上角，
  较长时会延伸到第一个小节左侧，正文行盒自动避开它
- 小节标题（`h2`）是独立格式化上下文，它的**通栏细线会在照片左侧
  8mm 处收住**，不会伸到照片下面或碰到照片
- 第一个小节标题从**联系方式行底缘**起算，向下一个小节间距 token，
  与「工作经历 → 教育背景」等其他小节的间距完全一致（不参考照片底缘）
- 位置由 `renderMarkdown` 自动包裹头部生成；想改大小改
  `src/styles/resume.css` 里的 `.resume-photo-frame`

> 建议上传正面免冠照，原图不小于 295 × 413 像素，否则放大后可能发虚。

> 照片位依赖模板头部的约定：第一个 `##` / 列表之前的内容被视为头部
> （姓名、职位、联系方式）。照片会自动放在这个头部的右侧。

### 正文图片

点击「插入正文图片」会把图片插到光标处，压缩后写成：

```markdown
![photo.jpg](data:image/jpeg;base64,...)
```

优点：`.md` 和打印结果都是自包含的，不依赖图床或后端。
缺点：base64 会让 Markdown 里出现很长的一行，文件也会变大。
想调整压缩参数，改 `src/core/compressImage.ts`。

## 打印成 PDF

点击「打印 / 保存 PDF」→ 在浏览器打印对话框里选择「另存为 PDF」。

- 纸张固定为 A4，页边距为 0（真正的页边距由 `#resume-paper` 的 padding 控制）
- 建议在打印设置里勾选「背景图形」，否则主题色/边框可能不显示
- 如果预览是一页、打印却多出空白页，检查 `src/styles/print.css` 里
  `#resume-paper { padding-bottom: 0 !important }` 是否还在

## 注意

Markdown 以 `html: true` 渲染并通过 `innerHTML` 注入，**没有做 HTML 清洗**。
这意味着 Markdown 里的 `<script>` 或事件属性会被执行。
这个工具面向本地、自己写自己的简历；不要把来路不明的 Markdown 粘进来。
